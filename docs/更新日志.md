## 0.3.0 - 2026-10-22

> 架构评审后的四轮整改。**含契约级变更，升级前请先读最后的「兼容性」一节。**

### 安全

- **生产启动硬门槛**：`CCCMS_DEBUG` 必须为 false、`CCCMS_SECRET_KEY` ≥32 字节、`CCCMS_CORS_ORIGINS` 非空且不含 `*`、`CCCMS_ADMIN_PASSWORD` 非默认且 ≥12 位；调度器与 API 行为一致（不满足直接退出）。
- **会话吊销真正生效**：登录不再清除 `user_cutoff`，水位只前进；改密、管理员重置密码、强制下线后旧令牌立即失效且不会因再次登录而复活，同时清理在线会话。
- **多角色数据范围取最严**：`merge_data_scope()` 用 `max()` 合并，任一角色的宽范围不再静默放大整个账号（与 06 文档一致）。
- **不再下发数据加密母密钥**：`/auth/me` 移除 `crypto_key`，前端 `stores/user.ts` 同步删除；持 `data_rule:*` 权限者也拿不到可用于离线解密的密钥。
- **分配角色补委派校验**：给用户挂角色时校验「不能授出自己未拥有的节点 / 更宽的数据范围」，堵住 `user:update` 自我提权。
- **匿名接口限流**：登录 20/min、验证码/找回密码 5/min（按 IP 分桶，可配置）；顺手修正重接口判定永远不命中 `/api/**` 的问题。
- **`/storage/**` 改为鉴权直出**：按 `sys_file.path` 反查 + `apply_scope()`，匿名 401、不可见 404；附件不再「知道链接即可读」。
- **凭据枚举与裸入参**：登录用户不存在时也执行一次哈希校验；`sendCode/reset` 改走 Pydantic 且账号不存在返回统一成功体。
- **移动端/第三方安全**：`/metrics` 白名单改用 `ip_allowed()`，支持网段；导出 CSV 走字段级脱敏管线。
- **存储后端不再谎报**：`CCCMS_STORAGE_DRIVER` 只接受 `local`，其它取值启动即失败（此前会静默写本地目录）。

### 错误码与文案

- **业务码与 HTTP 状态码解耦**：新增 `core/codes.py`（`BizCode`），响应体 `code` 为业务码（认证 101xx / 授权 102xx / 资源 104xx / 服务 105xx），HTTP 状态码保持协议语义。
- **多语言接线**：新增 `lang/zh-CN|en-US/error.json`，`Accept-Language` 命中翻译时返回对应语言，未命中回退原文；中间件 413/504 也带业务码与文案。
- 细分码已落位：登录失败 `10102`、账号停用 `10103`、验证码错误 `10105`、令牌过期 `10107`、CSRF 失败 `10108`、委派越权 `10203`、密码策略 `10106`、体积超限 `10413`。

### 数据与性能

- **不再用「全列子查询」做 count**：新增 `count_query()` 收敛派生表到主键一列，替换 15 处热点（日志/用户/公告/岗位/字典/导出/定时任务/租户/规则/角色/工作台）。
- **列表索引补齐**：`sys_log(tenant_id,id)`、`sys_log(path,create_time)`、`sys_log(row_hash)`、`sys_crontab_log(crontab_id,id)`、`sys_notice(tenant_id,pinned,publish_at,id)`、`sys_file(tenant_id,path)`。
- **分页封顶**：`PageLimit ≤ 200` 覆盖 log/dict/notice/post/export/online 与 `UserQuery`；角色列表由「全表捞出后切片」改为 SQL 分页。
- **鉴权上下文短缓存**：Redis 版本化缓存（TTL 120s），权限类写请求成功后 bump 版本；字典下拉 300s、工作台统计 60s。
- **批量操作去 N+1**：用户批量启停/删除/授权改为一次 `IN` 查询；公告「全部已读」改为批量 INSERT + 一条 UPDATE；`read_count` 改原子自增。
- **秒传按租户去重**：显式 `tenant_id + sha1 + size`，不再被「仅本人」数据范围收窄。
- **连接池**：新增 `pool_timeout=5s`、`pool_use_lifo`、可配 `pool_recycle`。

### 运维与工程化

- **Alembic 迁移体系**：`alembic.ini` + `migrations/`（0001 基线 / 0002 热索引 / 0003 附件路径索引）；`cli init-db` 与新增 `cli migrate` 走 `upgrade head`。
- **容器与流水线**：多阶段 `backend/Dockerfile`（非 root + HEALTHCHECK）、根 `docker-compose.yml`（mysql/redis/migrate/api/scheduler）、`.github/workflows/ci.yml`。
- **请求守卫**：全局 30s 超时（未开始响应时 504）与 `Content-Length` 体积上限（413）。
- **探针分级**：`/healthz` 把 Redis 降级为 `degraded` 信号，不再让 Redis 抖动摘掉全部实例。
- **导出转后台**：接口立即返回 `task_id`，后台流式生成（`session.stream` + 分块写盘），失败落状态；启动期把重启遗留的任务标记失败。
- **调度器心跳**：写 `cccms:scheduler:heartbeat`，`/metrics` 暴露 `cccms_scheduler_heartbeat_age_seconds`。
- **清理任务补齐**：`cccms.crontabLog.clean`（30 天）、`cccms.noticeRead.clean`（90 天），全部按 5000 行分批删除。
- **日志归档**：新增 `cccms.log.archive` 与迁移 `0004_log_archive`，把 90 天前未封存日志搬到 `sys_log_archive`（先 INSERT 再 DELETE，5000 行一批），不再只能选择「删掉」。
- **导出并发保护**：进程内并发闸门 + 单用户未完成任务上限（`CCCMS_EXPORT_MAX_CONCURRENCY` / `CCCMS_EXPORT_MAX_ACTIVE_PER_USER`），防止刷导出拖垮数据库。
- **未读判定改 `NOT EXISTS`**：公告未读列表与角标不再用 `NOT IN (子查询)`，避免 MySQL 物化整张已读表。
- **RED 指标接入 `/metrics`**：`cccms_http_requests_total`、`cccms_http_request_duration_seconds`、`cccms_http_requests_in_flight`，路由标签使用模板避免基数爆炸；另加 `cccms_db_pool_checked_out`。
- **导出优雅停机**：lifespan 关闭时取消在途导出任务并把状态落为失败，不再依赖 30 分钟后的启动期对账。
- **HTTP 契约测试**：新增 `tests/test_http_contract.py`，锁定 fail-closed 401、`/storage` 鉴权、业务码与 HTTP 解耦、`/metrics` 伪装 404、安全响应头等不变量（无需 MySQL/Redis）。
- **API 版本化**：业务路由同时挂载 `/api` 与 `/api/v1`（旧前缀保留一个发布周期）。
- **死代码清理**：删除 `core/sorting.py` 与 `PageParams`。

### 前端性能

> 首屏关键路径（入口 JS + vue + CSS）由 **504KB / gzip** 降到 **185KB / gzip**（-63%），
> 产物总体积 7.84MB → 3.16MB。以下为实测值（`npm run build` 同机对比）。

- **挂载不再等配置接口**：`main.ts` 去掉 `Promise.race([configUi, 2.5s]) → mount` 的阻塞（该接口一度能把 LCP 拖满 2.5s）；改为「缓存同步回填 + 接口静默校正」，首屏 loader 跟随 `router.isReady()` 收起。
- **Element Plus 真按需引入**：`unplugin-vue-components` + `unplugin-element-plus`，删除 `app.use(ElementPlus)` 与全量 `index.css`。**注意**：`manualChunks` 里不能再给 `element-plus` 指定固定 chunk —— 那会把 109 个组件全部强制打入产物（946KB→按需后仅用到的部分），已在 `vite.config.ts` 注释中写明原因。产物中 `resolveComponent("el-*")` 为 0，说明组件/指令均已编译期解析。
- **图标字体只产 woff2**：构建期删除 remixicon 的 eot/ttf/svg/woff 引用与文件，dist 减少 4.2MB。
- **echarts 懒加载**：从工作台模块顶层静态 import 改为数据到达后再取（`utils/echarts.ts` 用具名导入保证 tree-shake），登录后首屏少下 523KB。
- **英文语言包按需**：`en-US` 改为动态 import（-48KB 入口），切换语言先中文兜底、包到自动刷新。
- **工作台 CLS**：指标卡与图表骨架改为「按权限同步渲染 + 固定高度占位」，消除数据到达时的整块下推。
- **导航预取**：侧边栏 `mouseenter/focus` 即预取对应路由 chunk；路由过渡 0.18s→0.11s 并支持 `prefers-reduced-motion`。
- **重复访问走 Service Worker**：`public/sw.js` 对带哈希的 `/assets/*` 做 cache-first（HTML 不入缓存，升级不受影响）。
- **交互细节**：`useTable` 最小 loading 300ms→120ms；NProgress 延迟 120ms 出现（快请求不再闪）；表格/图表的 `resize` 合并到单帧。
- **Nginx 参考配置补齐**：gzip/brotli（原配置未开，JS 裸传输）、`/assets/` 一年 `immutable`、`index.html` 与 `sw.js` `no-cache`，见 [02-安装部署](02-安装部署.md) §5.1（含验证命令）。

### 兼容性

- **响应体 `code` 语义变更**：错误时不再等于 HTTP 状态码。前端只判断 `code === 0`，已适配；**外部集成若比较过 `code == 401/403` 必须改为看 HTTP 状态码或新业务码**。
- 多角色用户的可见数据可能变少（最严合并），需要放宽时请显式调整角色档位。
- `/storage` 不再匿名可读；纯 Bearer 客户端与第三方外链需改用带令牌的下载入口。
- 生产新增启动门槛（CORS / SECRET_KEY / 管理员口令 / 存储驱动），升级前务必核对 `.env`。
- 存量库升级：`alembic stamp 0001_baseline` 后执行 `cli migrate`，再 `cli seed` 以写入新增的清理任务。

## 0.2.0 - 2026-10-22

### 安全（P0）

- **导出目录移出静态资源**：新增 `CCCMS_EXPORT_LOCAL_ROOT`（默认 `shared/exports`），导出文件不再落在 `/storage` 下，只能经 `/api/export/task/download` 鉴权下载。
- **菜单写入收口**：`sys_menu` 为全平台共享表，新增/修改/删除要求「超管 + 平台租户」，阻止租户级管理员篡改全局菜单。
- **阻止超管角色伪造**：创建或复制编码为 `super_admin` 的角色直接拒绝。
- **在线会话租户隔离**：会话记录新增 `tenant_id`，在线列表与强制下线只能作用于当前租户。
- **日志清理租户隔离**：过期日志清理任务注入执行租户；租户任务只清理本租户，平台租户才可跨租户清理。
- **回收站越权修复**：还原/彻底删除统一走 `apply_scope()`，并保护超管账号、`super_admin` 角色与平台菜单。
- **部门越权修复**：部门详情、选择器、写操作统一做数据范围可见性校验，避免「看不到却能改」。
- **字段解密收口**：前端解密密钥只下发给超管与拥有 `cccms:data_rule:save/update` 的角色，只读审计角色不再获得明文。
- **已封存日志禁止删除**：参与哈希链的日志行不允许通过后台删除，避免审计链断裂。
- **阻止平台租户内提权**：非超管不能授予 `super_admin` 角色，也不能修改、重置密码或停用超管账号；批量操作会跳过。
- **角色授权最小委派**：非超管只能授出自己拥有的权限节点，`data_scope` 不得比自身更宽。
- **系统刷新限平台超管**：`/api/system/refresh` 触发菜单重建时要求「超管 + 平台租户」，避免改写全平台菜单。
- **维护模式按租户隔离**：租户级维护不再提升全局会话水位，不会把其他租户全部强制下线。
- **附件软删除隔离**：删除时把文件移入 `shared/quarantine/`，旧 URL 立即 404；还原移回，彻底删除清理文件。
- **操作日志不再保存认证/配置响应体**：登录、切租户、找回密码、配置保存即使进入审计也强制 `result=NULL`；`redact()` 改为按键名包含 password/secret/token/code 脱敏，避免复合键（如 `mail.smtp_password`）漏网。
- **开发密钥跨进程共享**：dev 首次启动生成的 JWT/数据加密/审计签名密钥写入 `.dev-secrets.env`（已 gitignore），API、调度器、CLI 不再各生成一套。
- **找回密码冷却与生产边界**：生产未接入通道时在写 Redis 前直接 503；验证码改为 `GETDEL` 原子消费，比较使用 `compare_digest`。
- **登录锁定按租户隔离**：失败计数 key 加入 `tenant_id`，避免跨租户锁死同名账号。
- **在线升级限平台超管**：除 dev + 开关外，还要求当前租户为平台租户且操作者为超管。
- **附件隔离失败回滚**：文件无法移入隔离区时回滚软删除并返回 503，避免旧 URL 继续公开。
- **租户域名缓存主动失效**：修改/删除租户后清除旧域名与新域名缓存，不再等待 300 秒 TTL。

### 功能（P1）

- **分片上传契约修复**：`/file/upload/chunk` 接受 `file` 字段（兼容前端 FormData）。
- **数据规则契约修复**：
  - 受控表出参补充 `label`、`field_count`、`exists`，新建/编辑不再 422。
  - `options.tables` 返回表名、显示名与字段列表，前端表/字段下拉不再崩溃或显示空白。
  - 仍有规则引用的受控表禁止删除。
- **字段级规则真正生效**：用户、部门、附件、操作日志的出参应用 `hidden` / `mask`（`encrypt` 暂按掩码展示）；用户与部门的写入过滤只读/掩码字段，避免掩码值回填。
- **用户名复用**：唯一性校验排除已软删行，删除后可重新创建同名账号。
- **批量删除保护**：批量删除用户时跳过超管。
- **关联写入租户校验**：用户保存角色/部门/岗位时只接受当前租户且未删除的 ID。
- **字典校验**：字典数据必须属于当前租户的类型；分类不允许跨模块修改、不允许挂到自己的子孙下；删除分类校验模块。
- **配置覆盖**：租户保存不再改写全局默认行，而是生成租户覆盖行；`secret` 空值可显式清空。
- **通知更新**：未提交 `expire_at` 时保留原值；重复标记已读幂等，不再因唯一键冲突报错。
- **密码重置**：成功后吊销该用户全部令牌与在线会话；生产环境未接入通道时返回 503，不再「假成功」并把验证码写入日志。
- **导出过期校验**：下载前检查 `expires_at`，过期任务返回 404。
- **租户用户配额**：创建用户时校验 `max_users`（平台租户与 0 值不限）。
- **通知详情**：无 `cccms:notice:update` 的角色只能读取已发布且在投放范围内的通知。
- **批量分配**：未提交的字段保持原样（不再被默认空数组清空）；先整体校验角色/部门/岗位归属，非法 id 直接拒绝。
- **租户平台标记**：接口忽略 `is_platform`，只能由初始化脚本写入。
- **租户到期**：域名识别与缓存命中都检查到期时间。
- **代码生成器**：表结构查询、预览、生成统一限制在 dev / test 环境，生产不再暴露库表结构；修正生成代码的 `get_current_user` 导入位置。
- **定时任务**：立即执行增加 Redis 锁，避免与调度执行并发；调度执行注入租户上下文。
- **在线用户接口**：返回设备/系统/浏览器/登录时间/到期时间/是否当前会话，支持用户名、IP、时间范围筛选与排序。
- **列表筛选补齐**：通知（标题/级别/范围/时间）、附件（原名/时间）、日志（IP/参数/结果）、租户（名称/编码/联系人/时间）、定时任务与数据规则（回收站/时间）、角色（角色树节点）。
- **在线升级不阻塞事件循环**：git 调用改为 `asyncio.to_thread()`。
- **审计校验命令**：新增 `python -m cccms.cli audit-verify`。
- **本地一键启动**：新增 `python -m cccms.dev`，同时启动 API 与调度器；`uv sync` 仍只安装依赖。
- **自动清理任务**：平台租户新增「清理过期导出文件」与「清理未完成分片」两个内置定时任务。
- **上传 MIME**：以扩展名推导为准，客户端 `Content-Type` 仅兜底；图片类型移除 `svg`。
- **默认配置初始化**：`seed` 现在写入 18 个全局 `sys_config` 默认项；保存未知配置项返回 422，不再静默 `updated=0`。
- **Argon2 移出事件循环**：新增 `hash_password_async` / `verify_password_async`，并用信号量限制同时 4 个哈希；登录成功后按需 `needs_rehash` 自动升级旧哈希。
- **审计链校验分批**：`verify_chain()` 改为按 ID 分页，不再一次性加载全表；`from_id` 从上一个已封存哈希续接，避免误报 broken。
- **分片上传边界**：`save_chunk` 校验 `index < total_chunks`，不能再为一个声明 2GB 的文件写 10 万个分片。
- **工作台权限收口**：统计项先判断权限再查询，日志趋势与文件类型按对应权限裁剪。
- **菜单可见性去 O(n²)**：父节点查找改用已有 `by_parent` 索引。
- **数据规则 fail-closed**：字段/操作符/取值非法时返回空集，不再静默放行整表。
- **后端单元测试**：新增 `backend/tests/test_helpers.py`，覆盖文件名清洗、字段掩码、CSV 注入防护、租户到期判断、生成器命名、角色最小委派、错误码与缓存失效范围。

## 0.1.0 - 2026-09-18

### 首个可运行版本

- 后端：FastAPI + SQLAlchemy 2.0 async + MySQL 8 + Redis，分层 `api / services / schemas / models / core`。
- 前端：Vue 3 + Vite + TypeScript + Element Plus + Tailwind CSS 4。
- 身份：账号密码登录、图形验证码、JWT（Bearer / Cookie）、静默续期、令牌吊销、在线会话。
- 权限：路由级 `@permission` / `@no_auth` / `@no_login`，启动校验；RBAC 角色继承；按钮级 `v-auth`。
- 数据权限：角色 5 档 + 行级/字段级规则 + 受控表。
- 多租户：域名识别、手动选择、超管切换、平台租户。
- 模块：用户、角色、菜单、部门、岗位、字典、配置、租户、日志、在线用户、通知、附件、导出、定时任务、代码生成、回收站、在线升级。
- 审计：操作日志、登录日志、三层链路 ID、哈希链封存。
- 运维：`init-db` / `seed` / `check`、独立调度器、`/ping` `/healthz` `/metrics`、备份与发布文档。
