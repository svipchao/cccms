## 三、用户管理

页面：`pages/cccms/user/index.vue`

| 接口 | 方法 | 权限节点 |
|------|------|----------|
| `/api/user` | GET | `cccms:user:index` |
| `/api/user/read` | GET | `cccms:user:read` |
| `/api/user/save` | POST | `cccms:user:save` |
| `/api/user/update` | POST | `cccms:user:update` |
| `/api/user/delete` | POST | `cccms:user:delete` |
| `/api/user/batchStatus` | POST | `cccms:user:batch_status` |
| `/api/user/batchDelete` | POST | `cccms:user:batch_delete` |
| `/api/user/batchAssign` | POST | `cccms:user:batch_assign` |
| `/api/user/resetPassword` | POST | `cccms:user:reset_password` |

要点：

- 支持按用户名、昵称、邮箱、手机、部门、岗位、状态、时间筛选。
- 新建/修改时角色、部门、岗位只接受**当前租户且未删除**的 ID。
- 软删除后可复用用户名（唯一键含 `active_flag`）。
- 不能删除/停用自己；非超管不能删除、停用或重置超管账号；批量操作会跳过超管。
- 重置密码会吊销目标用户全部令牌。
- 列表与详情受数据范围与字段级规则约束。
- 批量分配时 `role_ids` / `dept_ids` / `post_ids`：不传表示保持原样，传空数组表示清空；非法 ID 直接拒绝，不会先清空再丢弃。
- 租户 `max_users > 0` 时创建用户会校验配额（平台租户与软删账号不计入）。

## 八、系统配置

页面：`pages/cccms/config/index.vue`

| 接口 | 方法 | 权限节点 |
|------|------|----------|
| `/api/config` | GET | `cccms:config:index` |
| `/api/config/save` | POST | `cccms:config:save` |
| `/api/config/ui` | GET | 公开 |
| `/api/system/refresh` | POST | `cccms:config:refresh` |

要点：

- 配置按 `group_key` 分组，支持 `input` / `input-number` / `switch` / `select` / `textarea` / `password` 等类型。
- `password`（兼容 `secret`）类型使用 AES-256-GCM 加密存储，读取时脱敏。
- `seed` 会写入站点、安全、界面、邮件等 18 个全局默认项；保存未知配置项返回 422。
- 全局默认行（`tenant_id IS NULL`）只有平台超管可改；业务租户保存时自动生成覆盖行。
- 保存后清理 Redis 配置缓存；`system/refresh` 可手动清理。
- `system/refresh` 的 `menu` / `perm` / `all` 范围会重建平台共享菜单，仅平台超管可调用。
- 前台初始化配置 `/config/ui` 返回站点名、Logo、备案号、主题等公开项。

## 十四、定时任务

页面：`pages/cccms/crontab/index.vue`

| 接口 | 方法 | 权限节点 |
|------|------|----------|
| `/api/crontab` | GET | `cccms:crontab:index` |
| `/api/crontab/targets` | GET | `cccms:crontab:targets` |
| `/api/crontab/logs` | GET | `cccms:crontab:logs` |
| `/api/crontab/save` | POST | `cccms:crontab:save` |
| `/api/crontab/update` | POST | `cccms:crontab:update` |
| `/api/crontab/delete` | POST | `cccms:crontab:delete` |
| `/api/crontab/run` | POST | `cccms:crontab:run` |

要点：

- 六段 Cron（秒 分 时 日 月 周），由 `croniter` 解析。
- 可调度任务来自 `services/crontab.py` 的注册表，只允许调用白名单函数。
- 重叠策略：跳过 / 允许并发。
- 失败按配置重试，记录到 `sys_crontab_retry`。
- 立即执行与调度执行共用同一把 Redis 锁，不会并发跑同一任务。
- 过期日志清理按租户隔离，只有平台租户可跨租户清理。

详见 [18-平台与运维](18-平台与运维.md)。
