# 目录结构

> 按「读代码时先看哪里」组织：仓库根 → 后端分层 → 前端分层 → 运行期目录。

---

## 一、仓库根

```text
cccms/
├─ backend/                  # FastAPI 服务
│  ├─ src/cccms/             # 应用包
│  ├─ .env.example           # 环境变量样例
│  ├─ pyproject.toml         # 依赖、Ruff、mypy、pytest 配置
│  └─ uv.lock
├─ frontend/                 # Vue 3 SPA
│  ├─ src/
│  ├─ vite.config.ts
│  └─ package.json
├─ shared/                   # 运行期目录
│  ├─ uploads/               # 附件（经 /storage 鉴权后读取，不是静态目录）
│  └─ exports/               # 导出文件（仅鉴权接口可下载）
└─ docs/                     # 本目录
```

> ⚠️ **注意**：`shared/exports` 与 `shared/uploads` 的访问模型不同，部署时不要合并或互换。

---

## 二、后端

```text
backend/src/cccms/
├─ main.py                   # create_app、中间件装配、生命周期
├─ config.py                 # Settings（CCCMS_* 环境变量）
├─ cli.py                    # init-db / migrate / seed / audit-verify / check
├─ scheduler.py              # 独立调度进程
├─ seeds.py                  # 菜单与按钮节点种子
├─ api/                      # 路由层：只做参数声明、权限声明、调用服务
├─ services/                 # 业务层：事务、校验、数据权限
├─ schemas/                  # Pydantic 入参与出参
├─ models/                   # SQLAlchemy 模型
├─ core/                     # 认证、RBAC、范围、审计、缓存、中间件
└─ db/                       # engine / session / Base
```

### 2.1 `api/`

一个业务域一个文件，文件名与 URL 前缀一致：

| 文件 | 前缀 | 说明 |
|------|------|------|
| `auth.py` | `/auth` | 登录、登出、当前用户、租户选择、找回密码 |
| `profile.py` | `/profile` | 个人资料、改密、我的登录设备 |
| `dashboard.py` | `/dashboard` | 工作台统计与快捷入口 |
| `user.py` / `role.py` / `menu.py` | `/user` `/role` `/menu` | 账号、角色、菜单与权限节点 |
| `dept.py` / `post.py` | `/dept` `/post` | 组织与岗位 |
| `dict.py` / `config.py` / `system.py` | `/dict` `/config` `/system` | 字典、配置、缓存刷新 |
| `data_rule.py` | `/data_rule` | 行级/字段级规则与受控表 |
| `tenant.py` | `/tenant` | 租户运营（平台） |
| `log.py` / `online.py` / `export.py` | `/log` `/online` `/export` | 审计、在线会话、导出任务 |
| `notice.py` | `/notice` | 通知公告与我的消息 |
| `file.py` | `/file` | 附件与分类、分片上传、鉴权下载 |
| `storage.py` | `/storage` | 本地驱动的附件读取（登录 + 数据范围，前端 `<img>` / 新窗口用） |
| `crontab.py` | `/crontab` | 定时任务与执行日志 |
| `generator.py` | `/generator` | 代码生成器 |
| `upgrade.py` | `/upgrade` | 在线升级（仅 dev） |
| `recycle.py` | `/recycle` | 回收站还原/彻底删除 |
| `observability.py` | 根路径 | `/ping` `/healthz` `/metrics` |

### 2.2 `services/`

与 `api/` 近乎一一对应，但**按业务概念**命名（如 `dict_service.py` 避免与内置 `dict` 冲突）。职责：

- 事务边界：服务内 `commit()`，路由不提交。
- 数据权限：查询前 `apply_scope()`。
- 领域校验：唯一性、父子环、租户归属、软删状态。
- 外部协作：Redis、文件系统、加密、导出。
- 投递：`services/mail.py` 提供 SMTP 发信（目前唯一消费方是找回密码验证码）。
- 存储：`services/storage/`（`base.py` 是驱动协议、`local.py` 是本地实现、`__init__.py` 是注册表与 `get_driver()`）。

### 2.3 `core/`

| 模块 | 职责 |
|------|------|
| `context.py` | `TenantContext` / `UserContext` / `ContextVar` 请求上下文 |
| `permissions.py` | `@permission` / `@no_auth` / `@no_login`、`GuardedRoute`、启动校验 |
| `auth_deps.py` | `load_user`、`get_current_user`、令牌解析与续期 |
| `rbac.py` | 角色继承、权限并集、数据范围计算 |
| `scope.py` | `apply_scope()`、行级/字段级规则编译 |
| `security.py` | 口令哈希、JWT 编解码 |
| `session.py` | Redis 在线会话、令牌吊销、单点踢出 |
| `middleware.py` | 请求 ID、租户识别、CSRF、操作日志、安全响应头 |
| `audit.py` | 审计哈希链封存与校验 |
| `config_store.py` | 键值配置读取、缓存、租户覆盖 |
| `envelope.py` / `errors.py` | 统一响应与异常 |
| `pagination.py` / `sorting.py` | 分页与排序白名单 |
| `ratelimit.py` | Redis 计数限流 |
| `redact.py` | 日志敏感字段脱敏（含 `mask_email`） |
| `delivery.py` | 渠道可达性判定（开关 ≠ 能发出去） |
| `params.py` | 公共查询参数（`PageLimit` 等），与 `pagination.py` 配套 |
| `metrics.py` | Prometheus 指标定义与注册 |
| `tenant.py` | 域名 → 租户解析（fail-closed） |
| `codes.py` | 业务码（与 HTTP 状态码解耦） |
| `net.py` / `time.py` / `cache.py` / `i18n.py` | IP 解析、时间、缓存、国际化 |

### 2.4 `models/`

按领域分文件，公共基类在 `db/base.py`：

- `BaseModel`：主键 `id`（`PKMixin`）
- `TimestampMixin`：`create_time`、`update_time`
- `TenantMixin`：`tenant_id`
- `SoftDeleteMixin`：`delete_time`
- `ActiveFlagMixin`：`active_flag`（参与唯一键，软删后释放唯一值）

### 2.5 `schemas/`

- 入参模型统一继承 `StrictModel`（`extra="ignore"`），前端多传的只读字段会被忽略。
- 出参模型显式列出可暴露字段，避免把 `password_hash` 等带出。
- 时间字段统一用 `LocalDateTime` 序列化为 `YYYY-MM-DD HH:MM:SS`。

## 三、前端

```text
frontend/src/
├─ api/                # 与后端一一对应的请求封装
├─ components/         # 通用组件（ArtTable、CronEditor…）
├─ composables/        # useTable、useRecycle、useCategoryTree…
├─ directives/         # v-auth 等
├─ layouts/            # BasicLayout
├─ locales/            # 中英文文案
├─ pages/cccms/        # 业务页面，按模块分目录
├─ router/             # 静态路由 + 动态菜单路由
├─ stores/             # Pinia：user / menu / app / worktab / notice / setting / exportTask
├─ types/              # 全局类型
└─ utils/              # auth、trace、progress、theme、echarts…（HTTP 封装在 api/request.ts）
```

| 目录 | 页面 |
|------|------|
| `dashboard` | 工作台 |

| `user` / `role` / `menu` / `dept` / `post` | 组织与权限 |

### 3.2 约定

- 菜单表 `component` 字段写相对路径（如 `cccms/user/index`），路由层用 `import.meta.glob('/src/pages/**/*.vue')` 解析。
- 页面不直接写 `axios`，统一走 `src/api/*.ts`。
- 权限指令 `v-auth="'cccms:user:save'"` 只控制显隐，真正的拦截在后端。

## 四、运行期目录

| 路径 | 内容 | 访问方式 |
|------|------|----------|
| `shared/uploads/` | 附件、头像、富文本图片 | `/storage/**`（反代到 FastAPI，登录 + 数据范围） |
| `shared/exports/` | 日志导出 CSV | 仅 `/api/export/task/download` |

两个目录都不应有 Nginx 的 `location` 静态直出：`/storage/**` 走鉴权路由，导出只走接口；否则等于用路径代替权限。

---

## 五、命名约定

| 对象 | 规则 | 示例 |
|------|------|------|
| 权限节点 | `cccms:<模块>:<动作>` | `cccms:user:save` |
| 表名 | `sys_` + 复数语义 | `sys_user`、`sys_dict_data` |
| 模型类 | 大驼峰单数 | `DictData` |
| 服务函数 | 动词开头 | `list_users`、`save_role_nodes` |
| 前端 API 文件 | 与后端前缀同名 | `src/api/dataRule.ts` |
| 页面组件 | `pages/cccms/<模块>/index.vue` | `pages/cccms/tenant/index.vue` |
