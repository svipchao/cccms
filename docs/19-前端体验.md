# 前端体验

> 说明后台的导航、页签、筛选、主题、水印与消息中心如何协同，以及为什么这样设计。

---

## 一、整体布局

```text
┌─────────────────────────────────────────────┐
│ 顶栏：折叠 / 面包屑 / 搜索 / 全屏 / 消息 / 设置 │
├──────────┬──────────────────────────────────┤
│ 侧边栏   │ 页签栏                            │
│ 菜单树   ├──────────────────────────────────┤
│          │ 页面内容（路由出口）               │
└──────────┴──────────────────────────────────┘
```

- 侧边栏由后端菜单树驱动，目录可折叠。
- 顶栏面包屑按当前路由生成。
- 页签栏记录已访问页面，支持关闭、关闭其它、刷新。
- 移动端自动收起侧边栏。

---

## 二、动态路由

1. 登录后拉取 `/menu/userTree`。
2. 只把 `type=2` 且 `component` 非空的节点注册为路由。
3. `component` 映射到 `pages/**/*.vue`，找不到时跳过并在控制台告警。
4. 路由 `meta.node` 写入权限节点，守卫做二次校验。
5. 登出时移除动态路由，避免换账号残留。

> ⚠️ **陷阱**：刷新时首帧会匹配 404 兜底。动态路由注册后必须按 `path` 重新导航，不能带 `name`，否则会解析回 404。

## 三、页签（Worktab）

- 每次进入新页面追加一个页签。
- 支持关闭当前、关闭其它、关闭全部、刷新。
- 页签固定在顶部，页面内容独立滚动。
- 登出时清空，避免跨账号残留。

设计取舍：

- 页签只存前端内存，不持久化，刷新后从当前路由重建。
- 不为每个页签保留组件实例（`keep-alive` 仅对白名单菜单开启），避免内存增长。

---

## 四、快捷导航与收藏

入口：顶栏搜索按钮，或 `Ctrl/⌘ + K`。

能力：

- 搜索全部可跳转菜单（标题、路径）。
- 回车跳转第一个结果。
- 收藏常用菜单，支持上移/下移/移除。
- 收藏按「用户 + 租户」隔离，存 `localStorage`。
- 菜单被删除后，收藏项自动跳过。

> **提示**：收藏只存路径，展示时回查菜单标题与图标，因此菜单改名后收藏会自动更新。

---

## 五、请求体验

- 全局进度条：路由切换与接口请求共用，按令牌聚合，全部结束才收尾。
- 401：清令牌、重置动态路由、跳登录，避免 401 风暴。
- 错误提示自动附操作 ID，便于排查。
- 文件下载复用同一 axios 实例，自动带鉴权与续期。

---

## 六、国际化

- 中英文文案分文件维护。
- 页面标题支持 i18n key 与后端已翻译标题两种来源。
- 切换语言后刷新 `document.title`。
- `npm run i18n:check` 校验键一致。

---

## 七、可访问性与细节

- 键盘焦点环：原生与自定义控件由 `index.css` 统一提供，Element Plus 组件用自身聚焦态（见 `docs/09-前端开发规范.md`）。
- 表单校验错误文案用 `--art-danger-text`，不直接用语义色（对比度不足）。
- 危险操作二次确认，并展示影响条数。
- 表格加载动画最短 120ms，避免闪烁。
- 移动端隐藏次要列，保留关键操作。
