# 前端组件参考

> 只列业务页面最常用的组件与 Hooks。属性表以当前代码为准，新增属性请同步本页。

## 一、ArtTable

`src/components/core/ArtTable.vue`

列表页的统一外壳：搜索区、工具栏、列设置、密度、排序、分页、回收站、汇总行。

### 1.1 Props

| 属性 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `columns` | `ArtTableColumn[]` | 必填 | 列定义 |
| `data` | `Record<string, any>[]` | 必填 | 行数据 |
| `loading` | `boolean` | `false` | 加载态 |
| `total` | `number` | `0` | 总条数 |
| `rowKey` | `string` | `id` | 行主键 |
| `height` | `number \| string \| 'auto'` | `'100%'` | 撑满容器用默认值；页面整体滚动用 `'auto'` |
| `size` | `'large' \| 'default' \| 'small'` | — | 表格默认尺寸（用户密度偏好优先） |
| `buttonSize` | `'large' \| 'default' \| 'small'` | — | 工具栏与插槽按钮默认尺寸 |
| `pageSizes` | `number[]` | `[10,15,30,50,100]` | 每页条数选项 |
| `selection` | `boolean` | `false` | 显示多选列 |
| `pagination` | `boolean` | `true` | 显示分页 |
| `tree` | `boolean` | `false` | 树形表格 |
| `storageKey` | `string` | 当前路由 | 列显隐持久化标识 |
| `recycle` | `boolean` | `false` | 回收站模式，操作列替换为还原/彻底删除 |
| `virtual` | `boolean` | `false` | 虚拟滚动（非树、非回收站时生效） |
| `defaultSort` | `{ prop, order }` | — | 表头初始排序（数据仍由后端排序） |
| `summaryMethod` | `(param) => string[]` | — | 自定义汇总行 |
| `summaryData` | `Record<string, string \| number>` | — | 按列展示后端汇总值 |
| `summaryText` | `string` | `''` | 汇总行首格文案 |
| `defaultHidden` | `string[]` | `[]` | 默认隐藏列 |

### 1.2 v-model

| 名称 | 类型 | 说明 |
|------|------|------|
| `page` | `number` | 当前页 |
| `limit` | `number` | 每页条数 |

### 1.3 事件

| 事件 | 参数 | 说明 |
|------|------|------|
| `refresh` | — | 点击刷新 |
| `page-change` | `page` | 页码变化 |
| `size-change` | `limit` | 每页条数变化 |
| `sort-change` | `{ prop, order }` | 列头排序 |
| `selection-change` | `rows` | 勾选变化 |
| `restore` | `row?` | 回收站还原（不传为批量） |
| `force-delete` | `row?` | 回收站彻底删除 |

### 1.4 插槽

| 插槽 | 说明 |
|------|------|
| `search` | 搜索表单 |
| `search-extra` | 搜索区右侧扩展 |
| `toolbar` | 工具栏左侧按钮 |
| `toolbar-right` | 工具栏右侧 |
| `column-<prop>` | 自定义单元格 |
| `action` | 操作列（回收站模式下不渲染） |
| `empty` | 空状态 |

> ⚠️ **陷阱**：`height` 必须与页面根布局匹配。`.art-fill` 页面用默认 `'100%'`；`.art-scroll` 或表格在 `el-card` 内时传 `'auto'`，否则会出现页面高度无限增长的 `ResizeObserver` 循环。

## 二、useTable

`src/composables/useTable.ts`

```ts
const table = useTable<UserRow, UserQuery>({
  api: (params) => userList(params),
  initialQuery: { username: '', status: undefined },
})
```

### 2.1 选项

| 选项 | 类型 | 说明 |
|------|------|------|
| `api` | `(params) => Promise<PageResult>` | 列表请求，自动带 `page` / `limit` / `sort` / `order` |
| `initialQuery` | `object` | 查询初始值，重置时回到这里；也是筛选记忆的字段白名单 |
| `pageSize` | `number` | 默认取后台配置 `ui.page_size` |
| `immediate` | `boolean` | 是否立即加载，默认 `true` |
| `transform` | `(list) => list` | 数据加工 |

### 2.2 返回值

| 名称 | 类型 | 说明 |
|------|------|------|
| `list` / `loading` / `total` | Ref | 列表状态 |
| `page` / `limit` | Ref | 分页 |
| `query` | Reactive | 查询条件 |
| `sort` | Ref | 当前排序 |
| `selection` | Ref | 勾选行 |
| `load` | `() => Promise` | 重新加载 |
| `search` | `()` | 回到第 1 页查询 |
| `reset` | `()` | 重置条件与排序 |
| `writeSort` | `(prop, order)` | 写入排序 |
| `onPageChange` / `onLimitChange` / `onSelectionChange` | 事件处理 | 直接绑定组件事件 |

### 2.3 内置能力

- 请求序号防竞态：慢请求晚返回不会覆盖新结果。
- 加载动画最短 300ms，避免闪烁。
- 筛选条件自动记忆到 `localStorage['cccms_table_filter:<name>']`。
- 命名方案存 `localStorage['cccms_table_filter_scheme:<name>']`，入口在 ArtTable 工具栏。
- `provide` 筛选与排序控制器，ArtTable 零配置接入。

### 2.4 useTableFilter

与 `useTable` 同文件导出，用于「一次性拉全量、前端过滤」的树表场景：

```ts
const { query, reset } = useTableFilter<Query>({ initialQuery: { name: '', leader: '' } })
```

只负责条件对象与持久化，不涉及分页与请求；过滤结果由页面自己的 `computed` 响应。

### 2.5 useTableSize

`useTableSize` 负责表格密度偏好的读写：紧凑 / 默认 / 宽松，写入 `localStorage`，ArtTable 与页面共享。

## 三、RecycleToggle 与 useRecycle

`components/core/RecycleToggle.vue`、`composables/useRecycle.ts`

```ts
const { recycle, toggle, onRestore, onForceDelete } = useRecycle('user', {
  reload: () => table.search(),
  ids: () => table.selection.value.map((item) => item.id),
  clear: () => { table.selection.value = [] },
})
```

| 项目 | 说明 |
|------|------|
| 列表接口 | 传 `trashed: recycle.value ? 1 : 0` |
| 表格 | `:recycle="recycle" @restore="onRestore" @force-delete="onForceDelete"` |
| 开关 | `<RecycleToggle :active="recycle" label="用户" @toggle="toggle" />` |
| `type` | 后端注册的类型：`user` / `role` / `dept` / `post` / `dict_type` / `dict_data` / `file` / `notice` / `crontab` / `data_rule` / `menu` / `category` |

> ⚠️ **注意**：`useRecycle` 必须在 `useTable` **之前**调用，列表闭包在 setup 阶段就会执行，此时 `recycle` 必须已初始化。

## 四、useCategoryTree

`composables/useCategoryTree.ts`

用于字典分类、附件分类等「左树右表」页面，封装：

- 分类树加载与选中。
- 新增/编辑/删除分类。
- 删除后刷新并清理选中。
- 与右侧列表联动。

---

## 五、CronEditor

`components/core/CronEditor.vue`

六段 Cron 可视化编辑器，采用「先选周期、再填时间」的方式：

- 周期：每秒、每 N 秒、每 N 分钟、每 N 小时、每天、每周、每月、自定义。
- 根据周期动态显示时/分/秒/日/周输入。
- 与 `useCronDescription` 配合展示人类可读描述。

---

## 六、ArtRichEditor

`components/core/ArtRichEditor.vue`

基于 Tiptap 的富文本编辑器：

- 标题、加粗、列表、引用、代码块、链接、图片。
- 图片上传走附件接口。
- 输出 HTML，提交前经 `utils/richText.ts` 清洗（DOMPurify）。

> ⚠️ **注意**：后端返回富文本时仍需信任边界处理，不要直接把未清洗的 HTML 插入 `v-html`。

---

## 七、ArtNodePicker

`components/core/ArtNodePicker.vue`

通用树选择器：

- 支持单选/多选。
- 支持「无上级」空值（提交时转为 `null`）。
- 用于菜单父级、部门上级、角色父级等。

## 九、Watermark

`components/Watermark.vue`

全局水印：

- 内容支持用户名、昵称、时间。
- 由 `utils/watermark.ts` 生成背景，配置来自 `setting` store。
- 在 `BasicLayout` 中挂载，导出/截图时仍可见。

## 十一、ArtSettingsDrawer

`components/core/ArtSettingsDrawer.vue`

- 主题色、暗色模式、布局、页签、水印。
- 配置写入 `setting` store 与 `localStorage`。

## 十二、v-auth

`directives/index.ts`

```vue
<el-button v-auth="'cccms:user:save'">新增</el-button>
```

- 超管直通。
- 仅控制显隐，不构成安全边界。
- 支持数组形式表示「任一命中」。
