## 二、待办详情

### 2.1 安全加固

#### P1-1（遗留）插件表租户化（方案 A）

- **现状**：方案 B 已落地 —— `cccms:data-scope-check` 的 R3 强制插件表「登记受控表 / 自带 `tenant_id` / 显式豁免」，把「忘配」从静默放行变成退出码 1；但隔离本身仍依赖配置正确性。
- **建议**：`cccms:plugin-create` 生成的 `db/schema.sql` 默认带 `tenant_id` + 索引，模型骨架默认 `$tenantScope = true`；存量插件建列并回填（不需要租户的显式 `false` 并进豁免名单）。
- **验收**：新建插件的表 `DESC ks_xxx` 含 `tenant_id`；未加列且未豁免的插件表继续被 R3 挡住。
- **工作量**：3~5 pd（含存量迁移方案与文档）。

#### R-12 开发依赖告警处置（tinypool / esbuild / @vitest/mocker）

- **现状**：2026-10-22 实测完整 `npm audit` 剩 `6 vulnerabilities (3 moderate, 1 high, 2 critical)`，**全部在开发依赖树**：
  - `tinypool@<=2.1.1` — **critical ×2**：GHSA-5gmw-xhrv-c9v3 / GHSA-85c8-ppgw-ccpr（原型污染 gadget 经 `worker` 选项导致 RCE），由 `vitest` 传递引入；
  - `esbuild@<=0.24.2` — moderate：GHSA-67mh-4wv8-2f99（开发服务器可被任意站点读取响应）；
  - `@vitest/mocker@<=4.1.11` — moderate。
- **问题**：三者都不进生产包（`npm audit --omit=dev --audit-level=high` 已 **0 漏洞**），但完整 `npm audit` 为红，且 `tinypool` 是 critical —— 会让「本地审计」与「CI 门禁」结论不一致，容易被误读成门禁放水。
- **建议**：唯一修复路径是 `npm audit fix --force` → `vitest@4.1.12`（**breaking**）。暂不升级，原因：vitest 4 需回归 9 个测试文件 / 96 条用例与 `test:coverage` 的 `CORE_MODULES` 配置，且 `tinypool` 只在跑测试进程时可达（不暴露给最终用户）。计划与「工具链升级（Vite 大版本）」合并为一次独立变更。
- **验收**：生产依赖审计保持 0 告警；开发依赖在 vitest 4 升级后清零，或判定「不修」转入 [更新日志 · 明确不做](更新日志.md#附录--明确不做)。
- **工作量**：1 pd（升级 + 回归）。

### 2.2 性能与可观测

#### P2-11 性能基线与压测沉淀

- **现状**：性能优化点（数据权限请求级缓存、在线会话分段扫描）均来自设计推断，无实测基线，后续改动无法判断是否回归；N+1 除导出外未系统排查。压测脚本已就绪：[`server/loadtest/baseline.js`](../../server/loadtest/baseline.js)（k6，一条命令跑 6 个接口，支持 TOKEN / 账号密码两种鉴权），运行说明见 [11-常用命令与运维 §9.1](11-常用命令与运维.md#91-性能基线p2-11)。
- **建议**：在**目标数据量 + 目标硬件**的压测环境跑一次，记录 P95 / QPS / DB 查询数，填入 §9.1 的基线表；发现的 N+1 独立立项。
- **验收**：6 个接口有可复现基线且写入文档，脚本一条命令可跑。
- **工作量**：1 pd（脚本已完成，剩余为实测与记录）。

## 三、维护约定

1. **先登记再动手**：新增功能前先在 §一 登记（含工作量），方案写进 §二；**完成后从本文件移除**，实现与验收结论写入更新日志对应版本。
2. **一个功能只有一个编号**：登记前检索全文，重复的只在原编号下补细节。
3. **判为「不做」**：从本文件移除，写进 [更新日志 · 明确不做](更新日志.md#明确不做) 并写明原因。
4. **依据可核验**：条目须写明 `文件:行号`，无法确认的标「待确认」，不以推测代替事实。
5. **验收口径**：接口可用 + 页面可用 + 权限节点已生成 + 文档已更新 + 通过 [08-后端开发规范 · 提交前检查清单](08-后端开发规范.md#十四提交前检查清单)。
