| S-04 | 权限变更即时通知 | 角色/菜单变更后提示在线用户刷新 | P2 |
| S-05 | API Key | 对外开放接口的机机鉴权，与用户令牌隔离 | P2 |

## 八、完成标准

一项任务从「待办」移到「更新日志」需同时满足：

1. 代码合并，`cli check`、`ruff`、`mypy`、测试通过。
2. 有对应的测试或用例覆盖关键分支。
3. 文档已更新（机制、接口、配置、运维步骤）。
4. 本文件移除该条目，并在 [更新日志](更新日志.md) 增加记录。
